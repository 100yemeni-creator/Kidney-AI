# مشروع تصنيف صور الكلى

مشروع تعلم عميق لتصنيف صور الكلى إلى أربع فئات باستخدام VGG16.

## الفئات

- Cyst: كيس
- Normal: طبيعي
- Stone: حصوة
- Tumor: ورم

## تشغيل الواجهة

تشغيل الواجهة لا يبدأ تدريبًا جديدًا. تحتاج إلى Python 3.8
والاعتماديات المذكورة في requirements.txt وملفات النموذج المحلية.

أنشئ بيئة العمل وثبّت الاعتماديات:

```bash
conda create -n kidney_mlops python=3.8.20 -y
conda activate kidney_mlops
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

تأكد من وجود هذين الملفين داخل مجلد models:

- `best_finetuned_model.h5` — النموذج المحسّن المستخدم في الواجهة.
- `fine_tuned_confidence_uncalibrated.json` — إعداد درجة النموذج.

يتوفر أيضًا النموذج الأساسي باسم `best_candidate_model.h5`.

لتشغيل الواجهة من مجلد المشروع:

```bash
python app.py
```

افتح هذا العنوان في المتصفح:

`http://127.0.0.1:5000`

تقبل الواجهة صور JPG وJPEG وPNG وBMP وTIFF وWEBP،
بحد أقصى 10 ميغابايت، وتعرض الفئة المتوقعة ودرجات الفئات الأربع.

## ملفات النماذج

أوزان النماذج بامتداد `.h5` مستثناة من Git. لذلك لا يكفي استنساخ
المستودع وحده لتشغيل الواجهة على جهاز جديد؛ يجب توفير الملفات السابقة
ووضعها في مجلد models. لم يتم نشر إصدار GitHub يحتوي على الأوزان بعد.

## بيانات الصور

المجموعة المحلية تتكون من 11,929 صورة:

- التدريب: 8,348 صورة.
- التحقق: 1,788 صورة.
- الاختبار: 1,793 صورة.

لم يظهر تطابق تام في قيم SHA-256 بين مجموعات البيانات عند الفحص السابق.
لكن فحص التشابه البصري كشف صورًا شديدة التشابه بين المجموعات، ولا تتوفر
معرّفات المرضى أو الدراسات. لذلك لا يثبت عدم التطابق التام استقلال الصور
على مستوى المرضى.

صور البيانات وملف manifest والأرشيفات تبقى محلية ومستثناة من Git.

## أوامر التشغيل

لعرض الأوامر المتاحة دون بدء التدريب:

```bash
python main.py --help
```

الأوامر التالية تنفذ عمليات فعلية:

```bash
python main.py train-baseline
python main.py fine-tune
python main.py evaluate-validation
```

لا تشغّل هذه الأوامر لمجرد فتح الواجهة. كما أن `dvc repro`
يشغّل مراحل خط العمل، بما فيها التدريب.

## نتائج التقييم وحدودها

في اختبار سابق، صُنفت الصور الـ1,793 في مجموعة الاختبار الحالية
كلها بصورة صحيحة وفق التسميات الموجودة. لكن صورًا شديدة التشابه ظهرت
عبر المجموعات، ولم تتوفر معرّفات المرضى أو الدراسات. لذلك لا تمثل
هذه النتيجة إثباتًا للأداء مع صور أو مرضى مستقلين جدد.

استُخدمت مجموعة الاختبار بالفعل، فلا ينبغي إعادة استعمالها لضبط النموذج.
درجة النموذج المعروضة حاليًا غير معايرة وليست ضمانًا لصحة التصنيف.

## حماية البيانات

- أوزان النماذج مستثناة من سجل Git العادي.
- لا ترفع كلمات المرور أو مفاتيح الوصول.
- لم تُنفذ عمليات commit أو push في خطوات التجهيز الحالية.
